# 🌳 Decision Tree, SVM & Naïve Bayes Machine Learning Assignment

## 📌 Overview

This repository contains my Machine Learning assignment covering three important supervised learning algorithms:

- Decision Tree Classifier
- Support Vector Machine (SVM)
- Naïve Bayes Classifier

The project includes theoretical explanations, Python implementations, model training, and accuracy evaluation using real-world datasets from Scikit-Learn.

---

### Concepts Covered:
- Information Gain

- Trained Decision Tree Classifier using Gini Impurity
- Calculated feature importance
